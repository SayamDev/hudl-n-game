# Asset provenance

- `public/icon.svg`: original geometric Hudl face authored for this project from the user's requested mascot and palette.
- `public/icon-192.png`, `public/icon-512.png`: rasterized from that SVG using local Chromium, via `scripts/capture.mjs`.
- `public/social.png`: original local HTML composition rendered by the same script, using the authored mascot and supplied product copy.
- `public/projects/hudl/scene-1/lottie.json`: original geometric vector scene, authored by `scripts/create-lottie.mjs`; no external images or fonts.
- Fredoka and Nunito: bundled through Fontsource, SIL Open Font License. License files are included in their npm packages.
- Interface icons: Phosphor Icons, MIT license.
- Emoji: Unicode characters rendered by the visitor's operating system. They are not third-party image downloads.

The original sticker-book presentation remains available as a prior design. Current generated illustration and third-party emblem provenance are documented below.

## Social Club redesign

Space Grotesk is self-hosted from @fontsource-variable/space-grotesk; OFL license at `public/fonts/space-grotesk-LICENSE.txt`. The geometric interlocking H mark in `public/icon.svg` is original vector work. `scripts/club-icons.mjs` renders the 192px/512px icons and HTML social image; all three have embedded origin metadata. Phosphor supplies the game and navigation glyphs. Classic assets are archived under `docs/design-archive/classic/`.

## Masked identities and deck motion

`src/components/Identity.tsx` authors twenty deterministic alibi characters from the existing avatar identifiers, with six palette colours, ten silhouette/face families and alternate accessories. Names remain the primary accessible player identifier. Game emblems combine consistent physical-deck shapes with Phosphor fingerprint, disguise, globe/location pin, acting hand and pointing glyphs. `public/projects/hudl/scene-2/lottie.json` is original transparent Lottie geometry generated by `scripts/create-club-lottie.mjs`: 100 frames at 60fps, deal/fan/settle, no raster or font dependencies. Official Skottie verification at frames 0, 50 and 99 is recorded in `.impeccable/review/remix/` and `docs/verification/remix-skottie.json`.

## Public README screenshots

`.github/assets/` contains Chrome captures of the real production preview, with demo crew names. Captured through `scripts/review-welcome.mjs` and `scripts/confirm-welcome.mjs`; no generated imagery or external photographs.
