# Crew review and explicit verbal voting

24 October 2026.

Selecting any game now opens the existing crew editor even if enough people are saved. Play again returns to that editor, then game settings; game settings also expose Edit crew. The editor asks whether the crew is the same this round and supports its existing add/remove/reorder controls. Remaining player IDs, avatars and scores are preserved. A new session is created only after crew review and settings; existing minimum-player checks remain authoritative. Active rounds do not expose crew mutation.

The existing point voting mode is labelled Out loud — tap the accused. It needs one selection by one phone user, rather than a ballot from each player. Imposter discussion includes We voted out loud; private voting offers the same escape on both the protected handoff and an open ballot. Switching clears partial votes, voter index, selected player and tie state. The accused must still be selected and confirmed, and their public reveal remains sealed until the group opens it. Secret pass-and-vote remains optional.

No additional persistence schema or game mode is needed. Verbal shortcuts change the current session mode without silently overwriting the saved preference for future games.
